## Verified scope

- Four real native targets: Windows MSVC and Linux GNU, each on x86_64 and ARM64. Source builds pin
  Rust 1.100.0.
- All baseline suites plus five v1.0.0 security, bug, concurrency, feature acceptance and media branch
  suites passed across all four native targets and the coverage runner. Region coverage: **85.5671%**
  (20,922 / 24,451 regions). Branch coverage: **80.0267%** (4,800 / 5,998 branches). The 85/80 floors
  are unchanged.
- Highlights shipped in 1.0.0: 13 MCP tools (adding `list_jobs`), MCP `notifications/progress` updates,
  non-blocking `wait: false` background creation for `openai-responses` and `gemini-interactions`,
  animated GIF support (`output_format: "gif"`, `frame_count`, `frame_duration_ms`, multi-frame
  `GIF87a`/`GIF89a` byte preservation), 11 media modes (adding `video-to-audio` via `fal-ai/mmaudio-v2`),
  muxed MP4 `mp4a`/`Opus` audio track validation, `WAVE_FORMAT_EXTENSIBLE` WAV, safe Khronos GLB 2.0
  extensions, opt-in custom `falContract` endpoints, OmniRoute `/v1/fal` gateway support, DNS/redirect
  SSRF hardening and SQLite WAL/lease concurrency hardening.
- All eight published archives and `.sha256` sidecars are the original signed CI artifacts. GitHub's
  server-side asset digests match the local SHA-256 of every file.

The downloaded Windows x64 archive was extracted alongside `0.5.0`. `bin/numera-gen-mcp.exe --version`
reported `numera-gen-mcp 1.0.0`, publisher `KiaroSama`, source `f3e3165350d87b16665a0cc173ae046b30cbb961`,
signer `31ccb588…`, `Trust: self-signed; not public OS trust or Apple notarization`, and 1,031,073
embedded logo bytes. Authorized live low-cost end-to-end tests verified direct fal `flux/dev` image,
OmniRoute `/v1/fal` `flux/dev` image, OpenAI `gpt-image-2.6-flare` image and 4-frame animated `GIF89a`,
direct fal `edit_image` (`flux/dev/image-to-image`), `stable-audio` WAV, `kling-video` MP4,
`fal-ai/mmaudio-v2` muxed MP4 (`track_count=2`, `audio_codec=mp4a`), `fal-ai/trellis` GLB mesh,
`list_jobs`, `get_media_output_info`, and live `notifications/progress` events with zero secret leaks
across operational logs.
