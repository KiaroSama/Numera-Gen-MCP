## Verified scope

- Four real native targets: Windows MSVC and Linux GNU, each on x86_64 and ARM64. macOS is removed in
  this release. Historical macOS evidence and the 0.2.0/0.3.0 macOS archives are unchanged.
- All 470 frozen cases bound to applicable execution across five contexts. Region coverage
  85.34026678724848% (22115 regions, 18873 covered), branch coverage 80.69880418535126% (5352 branches,
  4319 covered). The 85/80 floors are unchanged.
- Both executables include the approved publisher, product, version and source identity and the
  original logo. Windows Authenticode and Linux signed-manifest byte authentication passed. Real
  unsigned, tampered and wrong-signer controls passed, as did extracted SDK stdio/HTTP acceptance after
  publisher inputs were removed.
- The eight published archives and sidecars are the original signed CI artifacts. Nothing was rebuilt
  or repacked. GitHub's server-side asset digests match the local SHA-256 of every file, and every
  sidecar `sha256sum -c` check passed.

## Host check

The downloaded Windows x64 archive was extracted into a temporary folder. `bin/numera-gen-mcp.exe
--version` reported `numera-gen-mcp 0.4.0`, publisher `KiaroSama`, source `582580b`, signer
`31ccb588…` (unchanged from 0.3.0), `Trust: self-signed; not public OS trust or Apple notarization`,
and an embedded logo, then exited 0. No setup, provider call or paid submission was made. Install,
Update, Diagnose and a live `bridge` session were not repeated for 0.4.0 on this host.
