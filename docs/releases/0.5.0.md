# Native 0.5.0 verification

[Download Release 0.5.0](https://github.com/KiaroSama/Numera-Gen-MCP/releases/tag/v0.5.0), published 2026-11-18.
Binary build source: `ab667a7d84371b10b15a3aced3f98dbcc9449ff4`.
[Qualification run 44317635481](https://github.com/KiaroSama/Numera-Gen-MCP/actions/runs/44317635481),
attempt 1, passed all six qualification jobs. [Protected signing
run 44323885497](https://github.com/KiaroSama/Numera-Gen-MCP/actions/runs/44323885497), attempt 1, passed
all four native signing targets and the signed collector at the same commit. Each run executes half of
the matrix by design, so the two runs together cover the complete release.

## Verified scope

- Four real native targets: Windows MSVC and Linux GNU, each on x86_64 and ARM64. Source builds pin
  Rust 1.100.0.
- All 470 frozen cases bound to applicable execution across five contexts. Region coverage
  85.635432305926% (22646 regions, 19393 covered), branch coverage 80.73089700996677% (5418 branches,
  4374 covered). The 85/80 floors are unchanged.
- The dual-provider `.env` loader and model routing are covered by native unit tests and by
  `tests/rust/env_acceptance.rs`. That covers the shipped template, two isolated connections, a
  per-connection credential check, fal-only, the legacy `PROFILE=fal` layout and invalid layouts, all
  without key disclosure. No live provider was contacted.
- The eight published archives and sidecars are the original signed CI artifacts. Nothing was rebuilt
  or repacked. GitHub's server-side asset digests match the local SHA-256 of every file, and every
  sidecar `sha256sum -c` check passed.

## Host check

The downloaded Windows x64 archive was extracted into a temporary folder. `bin/numera-gen-mcp.exe
--version` reported `numera-gen-mcp 0.5.0`, publisher `KiaroSama`, source `ab667a7…`, signer
`31ccb588…` (unchanged from 0.4.0), `Trust: self-signed; not public OS trust or Apple notarization`,
and an embedded logo, then exited 0. No provider call or paid submission was made.
