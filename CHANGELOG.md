# Changelog

## 0.3.0 - 2026-11-14

The current source adopts Numera Gen MCP and `numera-gen-mcp`, adds explicit per-model media kinds
and transformation modes, and authors fal queue orchestration for image, video, audio and 3D outputs.
The ten legacy image tools remain alongside `generate_media` and `get_media_output_info`.
All 51 original first-party Python/JavaScript/PowerShell executables are replaced by Rust;
their hashes, scenario maps and immutable expected data remain available. Native protection,
identity/custody maintenance and synthetic DPAPI fixtures replace active PowerShell callers. A small
standard-library Rust bootstrap owns substantive preparation logic; native libraries and fixed OS
commands remain permitted, with only a documented minimal pre-Rust seed.

Manual qualification runs six-target native tests, release builds, production coverage and the
execution collector on the exact selected commit. Source preparation and protected signing are
separate operations. GLB validation decodes each index accessor once and checks its maximum against
each primitive's vertex count. LLVM reporting retains the 300-second wall / 180-second output-idle
budget and unchanged coverage floors.
The current PR requires its own successful CI; earlier qualification failures are
recorded in [test results](docs/TEST-RESULTS.md). Source-authored corrections keep leaf SDK children
within outer POSIX harness containment, reject stale evidence after checkout HEAD changes, and add
read-only qualification of an exact 51-file retirement successor without deleting originals.
Current manifests select RMCP3.9.0, UUID1.29.2, flate2 1.1.11 and ZIP9.5.0. Successful hosted
[preparation42711139081](https://github.com/KiaroSama/Numera-Gen-MCP/actions/runs/42711139081)
on `370422d` returned a candidate lockfile and Rust formatting patch only, without compilation, tests
or signing inputs. Assertion parity, six-target runtime/package verification and genuine signatures
remain required for any later edit.
Reinstalling identical bytes no longer stages a redundant rollback copy of every member. Staging
flushes and virus-scans each file it writes, which dominated the Windows ARM update; a published
member already holds the previous bytes, so an identical member needs no `old-*` snapshot. Rollback
restores only members that actually changed. Verification, locking, replacement and rollback
semantics are unchanged.

At the owner's request, current first-party code now uses GPL-3.0-or-later, with the complete GPLv3

## Historical TypeScript changes - 2026-10-05

Authoritative upstream failures/cancellation now close lifecycle capacity through fenced transitions.
Empty orphan allocations release unused journal reservations without deleting uncertain receipts.
Targeted cancellation distinguishes backend dispatch from confirmed terminal status; retained originals
and storage recovery remain independent. MCP client/server update together to2.3.1.
Real two-host stdio acceptance covers terminal states and restarts. Concurrent initial WAL setup handles
bounded database lock contention, and explicit original-job recovery can publish completed images after
local wait cancellation without another generation request.

Use the stable native TypeScript7 compiler for typecheck/build alongside the official TypeScript6
API compatibility package for type-aware ESLint. Explicit compiler paths avoid executable collisions;
normal dependency resolution and existing verification gates remain enforced.

Recovery changes passed hosted Windows/Linux/macOS validation on320f903. Renewable
writer fencing and a bounded private result journal preserve received originals for storage recovery
without paid resubmission. Output index/receipt relationships commit together, with stable publication
hash reconciliation. Directory creation handles verified competing directories safely. Scalar JSON
editing rejects excess references instead of dropping them. Persisted aspect/tier evidence drives the
same original-dimension checks in normal and recovered completion. Capability discovery exposes
sourced Flash/Pro/GPT Image limits separately from route safety ceilings and account availability.
